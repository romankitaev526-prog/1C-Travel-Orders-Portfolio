# Учебная конфигурация 1С: Управление туристическими поездками

Учебный проект по курсу «Разработчик 1С».

---

## Описание проекта

Конфигурация предназначена для автоматизации продажи туров и управления поездками. Реализован полный цикл: от ведения справочников до оформления договоров, предварительных соглашений, оплат и отчетности.

---

## Функциональные возможности

**Справочники:**
- Организации
- Сотрудники
- Агенты
- Клиенты
- Страны мира
- Города мира
- Отели
- Виды номеров гостиниц
- Валюты
- Роли сотрудников

**Документы:**
- Договор
- Предварительное соглашение
- Оплата

**Отчеты (СКД):**
- Статистика по поездкам

**Регистры накопления:**
- Продажи туров
- Взаиморасчеты с клиентами

**Подсистемы:**
- Менеджмент
- Бухгалтерия
- Аналитика

**Прочее:**
- Общая форма
- Общие картинки (3 шт.)
- Печатная форма договора
- Перечисления: Статус клиента, Пол, Категории гостиниц
- Стили: БирюзаКорп, СтрСинийКорп

---

- Справочники: 10 шт.

- Регистры накопления: 2 шт.
- Отчеты в СКД: 1 шт.
- Перечисления: 3 шт.
- Подсистемы: 3 шт.
- Общие формы: 1 шт.
- Общие картинки: 3 шт.
- Печатные формы: 1 шт.
- Стили: 2 шт.

---

## Как запустить

1. Установите учебную версию 1С:Предприятие 8.3.
2. Создайте новую информационную базу.
3. Загрузите файл выгрузки через Конфигуратор → «Загрузить информационную базу».
4. Запустите 1С:Предприятие в режиме "Управляемое приложение".
