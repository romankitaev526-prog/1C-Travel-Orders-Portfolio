# Учебная конфигурация 1С: Управление туристическими поездками

Учебный проект по курсу «Разработчик 1С».

## Описание проекта

Конфигурация для автоматизации продажи туров и управления поездками.

## Функциональные возможности

**Справочники:**
- Организации
- Сотрудники
- Агенты
- Клиенты
- Страны мира
- Города мира
- Отели
- Виды номеров гостиниц
- Валюты
- Роли сотрудников

**Документы:**
- Договор
- Предварительное соглашение

**Отчеты (СКД):**
- Статистика по поездкам

**Регистры накопления:**
- Продажи туров
- Взаиморасчеты с клиентами

**Подсистемы:**
- Администрирование
- Менеджмент
- Бухгалтерия
- Аналитика

## Используемые объекты

- Справочники: 9 шт.
- Документы: 2 шт.
- Регистры накопления: 2 шт.
- Отчеты в СКД: 1 шт.
- Перечисления: 3 шт.
- Подсистемы: 4 шт.
- Роли: 3 шт.
- Стили: 2 шт.
